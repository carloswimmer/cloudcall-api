# CloudCall Desk API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the CloudCall Desk Go API (contacts, presence, simulated calls, dashboard, SSE, PostgreSQL, Docker, OpenAPI) in this repository, without Angular.

**Architecture:** One `cmd/api` process wired by `internal/app`. Domain packages own HTTP and SQL for their feature. `internal/event` is an in-memory SSE hub; `Publisher` and `SnapshotLoader` are the only interfaces. PostgreSQL is the source of truth. The API runs on the host; Compose runs only Postgres.

**Tech Stack:** Go 1.25+ (`net/http`, `database/sql`, `testing`), PostgreSQL 18, `github.com/jackc/pgx/v5/stdlib`, `github.com/google/uuid`, Docker Compose, hand-written `api/openapi.yaml`.

## Global Constraints

- Explanations in Portuguese; code, identifiers, and application messages in English.
- No ORM, no extra HTTP framework, no Redis, no broker, no API Docker image, no TypeScript generation in this repo.
- Client never sends `organizationId` or `userId` as authorization. SQL always filters by the seeded demo organization.
- `DEMO_MODE` must be `true` or process startup fails. Demo routes exist only in that mode.
- Error envelope `{ code, message, fieldErrors?, requestId }`. Codes: `validation_error`, `not_found`, `conflict`, `invalid_transition`, `version_mismatch`, `active_call_exists`, `presence_locked`, `internal_error`.
- JSON body limit 16 KiB. Pagination `{ items, total, page, pageSize }`, `page` from 1, `pageSize` default 20 max 100.
- CORS only for `CORS_ORIGIN` (default `http://localhost:4200`), no cookies.
- IDs are UUIDs generated by the app. Timestamps `timestamptz` UTC. Dashboard day uses organization IANA timezone.
- Publish SSE events only after the SQL transaction commits.
- stdlib `testing` only. No assert library. Integration tests use real PostgreSQL and skip if `DATABASE_URL` is unset.
- Execute only the requested task. Do not implement later tasks early. After each task: `gofmt`, `go test`, `go vet`, commit.
- Spec: `docs/superpowers/specs/2026-10-04-cloudcall-desk-api-design.md`. Tutorial mapping: tasks align with etapas 01, 07–12, 16–23, 26–27, 31.
- Official versions at plan time: Go supported pair includes 1.25/1.26 ([go.dev toolchain](https://go.dev/doc/toolchain), [Go 1.26](https://go.dev/doc/go1.26)); PostgreSQL current is 18, supported 18/17/16/15/14 ([postgresql.org](https://www.postgresql.org/docs/current/wal.html)); pgx v5 stdlib import `github.com/jackc/pgx/v5/stdlib`, `sql.Open("pgx", url)`.

```go
type App struct {
```

```go
package config

import (
    "fmt"
    "os"
    "strings"
)

type Config struct {
    HTTPAddr    string
    DatabaseURL string
    CORSOrigin  string
    DemoMode    bool
    LogLevel    string
}

func Load() (Config, error) {
    cfg := Config{
        HTTPAddr:    envOr("HTTP_ADDR", ":8080"),
        DatabaseURL: os.Getenv("DATABASE_URL"),
        CORSOrigin:  envOr("CORS_ORIGIN", "http://localhost:4200"),
        LogLevel:    envOr("LOG_LEVEL", "info"),
        DemoMode:    true,
    }
    if strings.TrimSpace(cfg.DatabaseURL) == "" {
        return Config{}, fmt.Errorf("DATABASE_URL is required")
    }
    if v, ok := os.LookupEnv("DEMO_MODE"); ok && strings.TrimSpace(v) != "" {
        if strings.EqualFold(v, "true") {
            cfg.DemoMode = true
        } else {
            return Config{}, fmt.Errorf("DEMO_MODE must be true in this MVP")
        }
    }
    return cfg, nil
}

func envOr(key, fallback string) string {
    if v := strings.TrimSpace(os.Getenv(key)); v != "" {
        return v
    }
    return fallback
}
```

```go
package db

import (
    "context"
    "database/sql"
    "fmt"
    "time"

    _ "github.com/jackc/pgx/v5/stdlib"
)

func Open(ctx context.Context, databaseURL string) (*sql.DB, error) {
    sqlDB, err := sql.Open("pgx", databaseURL)
    if err != nil {
        return nil, err
    }
    sqlDB.SetMaxOpenConns(10)
    sqlDB.SetMaxIdleConns(5)
    sqlDB.SetConnMaxLifetime(30 * time.Minute)
    if err := sqlDB.PingContext(ctx); err != nil {
        _ = sqlDB.Close()
        return nil, fmt.Errorf("ping: %w", err)
    }
    return sqlDB, nil
}
```

8. `Close` cancels all clients and stops the heartbeat goroutine.
